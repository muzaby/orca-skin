# 사례 — 0157 인증 플러그인 플랫폼: 역방향 탐색이 잡은 것

`docs/handoff/0157-auth-plugin-platform/verify.md` 의 r1→r2 기록에서 뽑았다. **이 스킬 §1(역방향
탐색)·§2(구현 보고 불신)·§5("무엇을 떼면 가능한가")가 왜 있는지**를 보여주는 한 케이스다.

전제: 설계·구현·검증이 **모두 같은 에이전트**였다(사용자 지시). 교차 검증이 없는 조건에서
아래가 잡혔다는 점이 중요하다 — 절차가 편향을 일부 대신했다.

---

## D1 — 어느 인수 기준에도 걸리지 않은 인증 오판

**결함**: `BrowserSessionStore.probe` 가 `fetch(..., { redirect: 'follow' })` 로 세션 유효성을
확인했다. 폐쇄망 ADFS 는 **미인증 요청을 로그인 페이지로 302** 한다. redirect 를 따라가면 로그인
페이지가 `200 OK` 를 주고, probe 는 그것을 "인증됨" 으로 읽는다. **인증되지 않았는데 valid
binding 이 만들어진다.**

**왜 인수 기준으로는 못 잡았나**: 16개 기준 어디에도 "probe 가 3xx 를 어떻게 다루는가" 가 없었다.
기준은 *설계가 의도한 것* 을 검사하지, *설계가 생각 못 한 것* 을 검사하지 않는다. 매트릭스만
채웠으면 16/16 으로 통과했다.

**무엇이 잡았나 — 형제 파일 비대칭**:

| 파일 | redirect 옵션 |
|---|---|
| `infra/auth/authenticated-fetch.ts` | `'manual'` |
| `infra/auth/browser-session-store.ts` (probe) | **`'follow'`** ← |

같은 디렉토리, 같은 목적(인증된 HTTP 요청), **다른 정책**. 이 비대칭을 보고 "왜 다르지?" 를
물은 것이 전부다. 자기 리뷰의 표현: "같은 파일군을 쓸 때 **한 번만 되짚었으면** 잡혔을 결함."

**수정(r2)**: `redirect:'manual'` + **3xx = 미인증** 판정으로 뒤집고, Location origin 을
allowlist 로 재검사. 회귀 테스트 — "ADFS 로그인 페이지로 302 되는 응답을 authenticated 로
오판하지 않는다".

> 이것이 `scan-surface.sh` 의 3번 출력(형제 파일 정책 키워드 비대칭)이 존재하는 이유다.

## D2 — 테스트에만 등장하는 심볼

`policy.ts` 의 `checkRedirect` 는 정의되고 테스트도 있었지만 **프로덕션 호출이 0건**이었다.
"redirect 를 재검사한다" 는 설계 의도가 코드로 이어지지 않은 것 — D1 과 같은 뿌리다.

테스트가 있으면 안심하기 쉽다. 하지만 **테스트 참조는 사용이 아니다.** 프로덕션 참조 0건은
ⓐ 죽은 코드이거나 ⓑ 배선 누락이며, 후자는 기능 결함이다.

## D3 — 미사용 export

`broker.ts` 의 `DEFAULT_PRESENTATION` 상수는 어디서도 참조되지 않았다. 무해해 보이지만,
**"기본 presentation 이 있다" 는 잘못된 계약 인상**을 코드가 준다. 제거.

## r1 이 멈춘 곳 — "electron 의존이라 테스트 불가"

r1 은 `browser-session-store.ts` 를 "electron 을 최상위 import 하므로 미테스트" 로 적고 #6 을
**⚠️ 부분** 으로 남겼다. r2 에서 **"무엇을 떼면 가능한가"** 를 묻고 판정 로직을 electron 비의존
`session-policy.ts` 로 분리했더니:

1. 순수 테스트가 붙었다(#6 → ✅, `partitionFor` 4케이스 + `classifyProbeResponse` 8케이스)
2. **`isAllowedOrigin` 이 features 와 infra 에 두 벌 존재**하는 것이 드러났다 — origin 판정
   규칙이 갈리면 한쪽만 고쳐지는 사고가 난다. 단일 구현으로 통합.
3. r1 이 "#6 부분 충족" 으로만 적고 넘어간 **근본 원인이 바로 이 구조**였음이 밝혀졌다.

즉 "테스트 불가" 는 판정이 아니라 **아직 안 물어본 질문**이었다.
