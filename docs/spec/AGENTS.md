# docs/spec/ — 외부 공식 문서 원문 미러

외부 벤더의 **공식 문서 원문**을 그대로 보관한다. PRD/TRD/`arch/`/해설 미러가 인용하는
**1차 출처의 저장소 로컬 사본**이다 (폐쇄망 대비 + 버전 고정).

## 편집 원칙 — 한 줄

**원문 미러는 편집 금지.** 원격 원문이 바뀌면 **통째로 덮어쓴다.** 부분 수정하면 다음 동기화가
불가능해진다 — 고치고 싶은 것이 있으면 *해설 미러* 로 옮긴다.

번역 결함·오탈자·미완성 표가 있어도 손대지 않는다.

## 2단 구조

| 층 | 위치 | 편집 | 무엇 |
|---|---|---|---|
| **원문 미러** | `docs/spec/<vendor>/**` | **금지** (덮어쓰기만) | 벤더가 발행한 그대로 |
| **해설 미러** | `docs/<vendor>-*-spec.md` | 가능 | Orca 채택 표기(✅/❌/⏳)·정리표·**안정된 절 번호** |

해설 미러는 절 번호를 *안정*시켜 다른 문서가 인용해도 깨지지 않게 한다. 원문 미러는 절 번호
안정성을 보장하지 않는다.

**충돌 시 원문 미러가 사실이다.** 해설 미러는 가공 결과일 뿐이므로, 어긋나면 해설 미러를 고친다.

## 무엇이 들어가고 안 들어가나

**들어간다**: 벤더가 발행한 *공식 문서 페이지* 의 원문(가능하면 마크다운).

**안 들어간다**: Orca 의 결정·채택 표기·해설·요약(→ 해설 미러) · 비공식 블로그·커뮤니티 가이드·발췌.

## 동기화 절차

갱신 책임은 사람이다. 자동 동기화는 없다.

1. 원문 URL 에서 마크다운을 받아 해당 파일을 **통째로** 덮어쓴다.
2. 변경이 해설 미러의 절·플래그·이벤트 스키마에 영향을 주면 **같은 PR 에서** 해설 미러를 맞춘다.
3. 커밋 메시지에 원문 URL 과 가져온 일시를 남기고, 위 매니페스트의 "마지막 동기화" 를 갱신한다.

## 새 벤더를 추가할 때

1. `docs/spec/<vendor>/` 를 만들고 원문을 그대로 저장한다 (소문자 한 단어 권장).
2. **위 매니페스트 표에 행을 추가한다.**
3. 파일이 많으면 그 디렉토리에 `INDEX.md`(파일별 인덱스)를 둔다 — **`AGENTS.md` 를 만들지
   않는다.** 미러 디렉토리의 규칙은 이 문서 하나로 충분하고, 계층마다 `AGENTS.md` 를 두면
   같은 정책이 복제돼 갈라진다.
4. 해설 미러가 필요하면 `docs/<vendor>-*-spec.md` 를 만들고 원문 미러를 1차 출처로 인용한다.
