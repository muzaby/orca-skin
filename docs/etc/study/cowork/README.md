## 원본을 두지 않는다

**캡처한 DOM 원본은 이 저장소에 없다.** 저장소가 공개이고 덤프에 사용자명·PC명·개인 폴더의
파일명 목록이 들어 있어 사용자가 업로드하지 않기로 결정했다
(`docs/handoff/0205-cowork-study-and-task-tile-suspend/plan.md` D-003).

그래서 **결론을 지지하는 증거는 이 문서들 안의 표가 전부다.** 이벤트 시퀀스·노트 분류·행 라벨은
원본에서 기계적으로 뽑은 값이며, 원본 경로에 남은 식별자는 `<사용자>` 로 가렸다. 표에 없는
주장을 나중에 이 조사에 귀속시키지 않는다 — 없으면 다시 캡처해야 한다.

## 이 문서의 지위

`docs/etc/` 는 **evidence 지 현재 규칙이 아니다**([`../../../INDEX.md`](../../../INDEX.md) §Evidence).

Orca 가 지금 무엇을 하는지는 코드와 `docs/arch/` 가 갖는다.
