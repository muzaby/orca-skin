## 관통하는 규칙 넷

1. **좌는 식별, 우는 조작.** 경계는 구분선이 아니라 축소 성질(`flex-1` vs `shrink-0`)이다.
2. **채움은 "새 표면이 열릴 때만".** 누를 수 있는가가 아니라 화면이 얼마나 바뀌는가가 기준.
   닫기가 ghost 인 것이 그 증거다.
3. **상태와 결과를 ARIA 속성이 소유한다.** `aria-pressed`(선택/토글) · `aria-expanded`(접힘) ·
   `aria-haspopup`(무엇이 열리는가). 스타일이 아니라 속성이 정본.
4. **닫기는 항상 마지막 · 항상 ghost · 항상 아이콘 전용.** 두 표면에서 예외가 없다.

## 캡처 범위의 한계

**한 시점의 DOM 두 조각이 전부다.** 메뉴·팝오버는 전부 닫힌 상태(`aria-expanded="false"`)라
**메뉴 항목을 하나도 보지 못했고**, diff 본문은 전 파일이 접혀 있다. 상호작용 이후의 DOM,
비활성/로딩 상태, 애니메이션은 관측되지 않았다 — **여기 표에 없는 것은 이 조사가 모르는 것이다.**
추론으로 채운 자리는 문서 안에서 "추정" 으로 표시했다.
