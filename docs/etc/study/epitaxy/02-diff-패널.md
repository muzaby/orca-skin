# diff 패널 — 버튼 구성

우측 타일로 뜨는 diff 뷰다. 버튼이 **두 계층**에 있고 성격이 완전히 다르다 —
헤더는 *패널 자신*을 다루고, 본문은 *내용*을 고른다.

```
┌────────────────────────────────────────────────────────────┐
│ [트리]  main → claude/0205-…      ▭      [설정] [펼침] [×] │  ← 헤더: 5조작
├──────────────┬─────────────────────────────────────────────┤
│ 파일트리      │  ▸ ChatTitleBar.tsx   app/…/chat/components │  ← 본문: 목록 3종
│  (전폭 행)    │  ▸ rightPanelTiles.ts app/…/chat/lib        │
│ ─────────────│                                             │
│ 커밋 목록     │                                             │
│  (전폭 행)    │                                             │
└──────────────┴─────────────────────────────────────────────┘
```

## 1. 헤더 — 5조작, 전부 ghost 아이콘

| 위치 | 자리 | 형태 | 상태/팝업 | 그 외 |
|---|---|---|---|---|
| 좌 | 파일트리 토글 | ghost, 아이콘 전용 | **`aria-pressed="true"`** | `aria-label="파일 숨기기"`, **`aria-keyshortcuts="Control+Shift+y"`**, `-ml-[4px]` |
| 좌 | `main → claude/…` | (버튼 아님) | — | 비교 대상 표시, 양쪽 `truncate` |
| 중앙 | 이동 핸들 | 투명 버튼 44×16 | — | `aria-label="이동"` + `aria-describedby="…-reorder-hint"`, `cursor:move`, 안에 32×3 알약 |
| 우 | 패널 설정 | ghost, 아이콘 전용 | `aria-haspopup="menu"` | |
| 우 | 펼치기 | ghost, 아이콘 전용 | — | |
| 우 | 닫기 | ghost, 아이콘 전용 | — | `epitaxy-pane-close-control` |

### 헤더에는 채움이 하나도 없다

컴포저 행은 일곱 자리 중 둘(diff·CI)이 채움이었다. **헤더는 다섯 조작 전부 ghost 다.**
경계가 분명하다 — 채움은 *내용에 대한 조작*에 주고, *그릇에 대한 조작*(접기·설정·크기·닫기)에는
주지 않는다. 헤더가 조용해야 안의 diff 가 읽힌다.

### 세 구역, 세 정렬

| 구역 | 정렬 | 간격 |
|---|---|---|
| 좌 (`relative z-[1]`, `pl-[4px]`) | 왼쪽 | **`gap-g3`** |
| 중앙 (`absolute left-50% translateX(-50%)`) | 정중앙 | — |
| 우 (`shrink-0`) | 오른쪽 | **`gap-g1`** |

좌우의 간격이 다르다. 우측은 **아이콘 전용 동종 버튼 셋** 이라 `gap-g1` 로 촘촘히 붙여 한 덩어리로
읽히게 하고, 좌측은 아이콘 + 텍스트가 섞여 `gap-g3` 로 벌린다. 토글 버튼의 `-ml-[4px]` 는 컨테이너
패딩(`pl-[4px]`)을 상쇄해 **아이콘 글리프가 패널 가장자리에 광학적으로 맞도록** 당긴 값이다.

중앙 핸들만 `absolute` 인 이유: 좌우 버튼 수가 바뀌어도 핸들은 항상 패널 정중앙에 있어야 하기
때문이다. flex 흐름에 두면 좌우 폭 차이만큼 밀린다.

### 이동 핸들이 `<div>` 가 아니라 `<button>` 이다

`cursor:move` + `touch-action:none` 으로 포인터 제스처를 잡으면서, **키보드 사용자에게는 포커스
가능한 조작으로 남는다.** `aria-describedby` 가 별도 안내문(`…-reorder-hint`)을 가리켜 "어떻게
움직이는가" 를 읽어 준다. 드래그 전용 어포던스(32×3 알약)는 `aria-hidden` 이고
`pointer-events:none` 이라 표적은 44×16 버튼 전체다 — **보이는 것보다 누르는 자리가 넓다.**

### 단축키가 DOM 에 선언된다

`aria-keyshortcuts="Control+Shift+y"`. 단축키 목록을 별도 문서·설정 화면으로 관리하지 않고
버튼 자신이 갖는다. 툴팁·도움말이 이 속성을 읽으면 항상 일치한다.

## 2. 본문 — 전폭 행 버튼 3종

본문의 모든 조작이 **행 전체가 버튼**(`w-full` + `text-left`)이다. 목록에서 "버튼처럼 생긴 것"을
찾아 누르는 게 아니라 행 아무 데나 누른다.

| 종류 | 상태 속성 | 구성 (좌 → 우) |
|---|---|---|
| 트리 · 디렉토리 | `aria-expanded` | chevron(12px) · 이름 |
| 트리 · 파일 | — | **스페이서 `w-3`** · 이름(`truncate flex-1`) · `+15` `-5`(`shrink-0`) |
| 커밋 항목 | **`aria-pressed`** | 2줄: 제목(`title`에 전문) / `sha` · 작성자 · `10m ago` |
| 파일 헤더 (우측) | `aria-expanded` | chevron(SVG, `-rotate-90`) · 파일명 + 흐린 경로 · `+15` `−5` |

### 스페이서가 정렬을 만든다

파일 행에는 chevron 이 없다. 대신 `<span aria-hidden class="w-3 shrink-0">` 빈 칸을 둔다.
**아이콘 유무로 들여쓰기가 흔들리지 않게** 자리를 비워 두는 것 — 디렉토리와 파일의 이름 시작
x좌표가 같은 깊이에서 정확히 일치한다.

깊이 자체는 인라인 `padding-left: 8 / 20 / 32 / 44px` (= `8 + depth×12`)로, 중첩 리스트가 아니라
**형제 버튼 평탄 리스트**다. 버튼 배열 하나라 위/아래 키 이동·필터가 인덱스로 끝난다.

### 상태 표현이 두 종류로 갈린다

- **`aria-expanded`** — 접힘/펼침 (트리 디렉토리, 파일 헤더). 되돌릴 수 있고 서로 독립.
- **`aria-pressed`** — 선택 (커밋 목록). `All changes` 포함해 하나만 참이다.

커밋 목록은 라디오 그룹이 아니라 `aria-pressed` 토글 배열로 만들었다. 선택된 항목만
`bg-fill-control text-primary` 로 채워지고 나머지는 `text-muted` — **본문에서 유일하게 채움을 받는
자리가 "지금 무엇을 보고 있는가" 다.**

### 좌측 컬럼 = 범위 선택 + 대상 선택

한 열(240px)을 위아래로 나눠 위는 파일트리(`flex-1`, 대상), 아래는 커밋 목록
(`shrink-0`, `max-height:40%`, 범위)이 쓴다. **어느 커밋을 볼지 고르고 → 그 안에서 어느 파일을
볼지 고른다**는 순서가 세로 배치로 표현돼 있는데, 시선 순서(위→아래)와는 반대다.

### 우측 파일 헤더는 sticky 버튼이다

`sticky top-0 z-[4]` 인 접기 버튼이 각 파일 블록 위에 붙는다. 스크롤 중에도 "지금 어느 파일인가"
가 화면에 남고, 그 자리가 곧 접기 조작이다 — 표시와 조작이 같은 요소다.

## 3. 아이콘 크기·굵기 체계

가변 폰트(Anthropicons)의 `font-variation-settings` 를 광학 보정에 쓴다.

| 자리 | 크기 | 굵기 |
|---|---|---|
| PR 상태 글리프 | 16px | **700** |
| 헤더 조작(트리·설정·펼침·닫기) | 16px | 533.3 |
| 인라인 표식(트리 chevron, CI ▾) | 12px | 577.8 |

**작을수록 두껍게** — 12px 글리프가 16px 과 같은 시각 무게를 갖도록 굵기를 올린다.
상태 글리프만 700 인 것은 색(`text-git-draft`)으로 의미를 나르는 유일한 표식이라 더 또렷하게 둔 것.

> 불일치 둘: chevron 을 트리는 **아이콘 폰트**로, 파일 헤더는 **인라인 SVG**(`-rotate-90`)로 그린다.
> 그리고 파일 수치가 트리는 `-5`(ASCII 하이픈), 헤더는 `−5`(U+2212)다.

## 4. 두 표면의 버튼 규약 대조

| 규약 | 컴포저 행 | diff 패널 | 일치 |
|---|---|---|---|
| 닫기 = 마지막 · ghost · 아이콘 전용 | ✅ | ✅ | ✅ |
| 채움은 "새 표면이 열릴 때만" | diff·CI 둘 | 없음(헤더) / 선택 행(본문) | ✅ 같은 기준 |
| 팝업을 `aria-haspopup` 으로 선언 | menu ×2, dialog ×1 | menu ×1 | ✅ |
| 상태를 ARIA 속성이 소유 | — | `aria-pressed` · `aria-expanded` | — |
| 조작에 툴팁 | 6/7 (닫기 제외) | 5/5 | ❌ **닫기에서 어긋난다** |
