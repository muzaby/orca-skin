# 4. 핵심 모듈

[← 3. 콜스택](03-콜스택-실행흐름.md) · [목차](README.md) · [다음: 5. 특장점 →](05-특장점.md)

---

| 모듈 | 책임 | 입력 → 출력 | 의존 |
|---|---|---|---|
| `agent/conversation_loop.py::run_conversation` | 턴의 에이전트 루프(모델 호출·툴 디스패치·재시도·압축·종료) | `user_message`, 히스토리 → 결과 dict | AIAgent, transports, tool_executor, turn_context, turn_finalizer |
| `run_agent.py::AIAgent` | 런타임 상태 머신: 모델/프로바이더/세션/예산/콜백 보유, SDK 호출 래핑, 툴 실행 진입 | 설정 → 살아있는 에이전트 인스턴스 | 거의 모든 `agent/*` |
| `agent/transports/*` (`ProviderTransport`) | LLM 경계 추상화. `convert_messages/convert_tools/build_kwargs/normalize_response` | OpenAI 포맷 메시지/툴 → 프로바이더 네이티브 kwargs, 그리고 raw 응답 → `NormalizedResponse` | 각 `*_adapter.py` |
| `tools/registry.py::ToolRegistry` | 툴 싱글톤 레지스트리(스키마+핸들러+가용성 체크). `register()`/`dispatch()` | 툴명+args → JSON 문자열 결과 | `model_tools.handle_function_call` |
| `model_tools.py` | 툴 발견(import 시 self-register), 정의 캐시, 인자 강제변환(`coerce_tool_args`), 디스패처 | 호출명/인자 → 결과 | registry, toolsets |
| `agent/context_engine.py` + `context_compressor` | 토큰 사용량 추적, 임계치(`threshold_percent=0.75`) 초과 시 `compress()` | 메시지/usage → 압축된 히스토리 | auxiliary 모델(conversation_compression) |
| `agent/memory_manager.py` + `curator.py` | 큐레이트 메모리(MEMORY.md/USER.md), 스킬/메모리 수명주기 전이(stale/archive/prune) | 대화 → 메모리 쓰기, 자동 전이 통계 | 백그라운드 리뷰 |
| `agent/background_review.py` | 턴 종료 후 에이전트를 포크해 "스킬/메모리 갱신?"을 평가, 스토어에 직접 기록 | 완료된 대화 → 스킬/메모리 갱신 | 데몬 스레드, 메모리/스킬 툴만 허용 |
| `hermes_state.py::SessionDB` | SQLite + FTS5(+CJK용 trigram) 세션 저장/전문검색 | 메시지 → 영속 저장, 검색 결과 | session_search 툴 |
| `tools/checkpoint_manager.py` | 파일변경 전 git 섀도 스냅샷(턴당 1회), 롤백 | 작업 디렉터리 → 커밋/복원 | git |
| `tools/delegate_tool.py` | 서브에이전트 스폰(병렬 워크스트림), 중단/추적 | goal/tasks → 서브에이전트 결과 | run_conversation(재귀) |
