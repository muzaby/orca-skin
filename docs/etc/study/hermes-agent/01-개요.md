# 1. 개요

[← 목차](README.md) · [다음: 2. 전체 아키텍처 →](02-전체-아키텍처.md)

---

- **목적**: "자가개선(self-improving) AI 에이전트". 단순 코딩 보조를 넘어, 경험에서 스킬을 만들고,
  대화 중 스킬을 개선하며, 지식을 영속화하도록 스스로를 자극(nudge)하고, 과거 대화를 검색하고,
  세션을 넘어 사용자 모델을 누적한다(README L18). CLI/TUI와 메시징 게이트웨이(Telegram, Discord,
  Slack 등)에서 동일 엔진을 구동하며, 로컬·Docker·SSH·Modal·Daytona 등 6개 백엔드에서 실행된다.

- **기술 스택**: Python 3.11. LLM SDK는 `openai==2.24.0`(chat.completions / responses),
  선택적 `anthropic==0.87.0`, `boto3`(Bedrock), `httpx`. **프레임워크 없음** —
  LangChain/LlamaIndex/AutoGen/CrewAI/LangGraph 의존성은 `pyproject.toml`에 전혀 없다(grep 결과 0건).
  저장소는 SQLite(FTS5), 영속성은 git 기반 체크포인트.

- **구현 형태**: **자체 구현(framework-free)**. 단, LLM 경계는 단일 호출이 아니라
  **provider 어댑터 계층**(`agent/transports/`의 Strategy 패턴 + `agent/*_adapter.py`)으로
  추상화되어 있다. 또한 `delegate_task`로 **서브에이전트를 스폰**하는 멀티에이전트 능력이 있으나,
  중심은 단일 from-scratch 루프이며 서브에이전트는 같은 루프를 재귀적으로 돈다.
