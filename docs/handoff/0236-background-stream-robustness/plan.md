# Part I — Product & UX Contract

## 1. Context / 목표

- 해결하려는 문제: 모르는 SDK 메시지를 **버린다**. 스펙은 원본 보존과 제한된 표시를 요구하고,
  Orca 는 스트림을 끊지 않는 것까지만 한다.
- 완료 후 달라지는 것: CLI 가 새 메시지 종류를 내보내기 시작해도 그 사실이 남는다. 같은 이벤트가
  재전달돼도 카드·통지·통계가 중복되지 않는다는 것이 **장치로** 잠긴다.
- 성공을 사용자 관점에서 한 문장으로: 앱이 모르는 것을 조용히 삼키지 않는다.
