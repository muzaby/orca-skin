**전달 순서**　Windows 기준 측정을 먼저 시작하고 세션 조립 실패를 우선 수정한다. 세션 페이지·행 ID·도구 ID 계약은 세션/Transcript/우측 패널 담당자가 공유한다. Markdown·Git·산출물이 쓰는 공통 워커 요청 규약은 워커 담당자가 소유한다. 각 담당자는 적용 전후 실행 위치, 보존한 동작, 재현 입력과 전후 결과를 제출한다.
