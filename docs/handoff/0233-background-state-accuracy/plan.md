# Part I — Product & UX Contract

## 1. Context / 목표

- 해결하려는 문제: 백그라운드 상태의 **모르는 것을 모른다고 말하지 않는다**. 스냅샷에서 사라진
  작업을 실패로 확정하고, 내부 유지 작업을 일반 배지에 섞으며, 매핑 없는 라이브 작업은 존재조차
  모른다.
- 완료 후 달라지는 것: "완료" · "실패" · "중단" · **"종료 사유 미확인"** · **"정리 중"** 이
  서로 다른 상태로 보인다.
- 성공을 사용자 관점에서 한 문장으로: 앱이 확정할 수 없는 것을 확정한 것처럼 말하지 않는다.
