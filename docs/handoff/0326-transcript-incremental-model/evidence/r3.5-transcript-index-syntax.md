역할은 단일 치환과 일대일로 세지 않는다. 예를 들어 dirty bit들의 긴 OR와 부모별 Map의 spread는 여러 역할이 하나의 실제 새로고침·철회에서 함께 실행된다. 범용 URL 파서·경로 파서·Map/배열 엔진 전체, 사용자가 공급하지 않는 내부 class 필드의 인위적 변조는 x 조회의 별도 증거로 세지 않았다. 소스 데이터의 첨부/도구·상위/하위·결과/미완료·제거/교체·같음/바뀜과 그 조합은 공개 transcriptIndexFor로 관측한다.

실제 추가 치환 34개는 TaskBoard 희소 patch·역방향 간선·제목 11개, 웹/파일 출처 11개, 표시 출력·메타데이터·행 참조 4개, 증분 철회 경계 3개, 첨부 우선순위·식별·표시 5개다. 각각 하나씩 적용해 34개 모두 회귀가 실패했다. 첫 오라클에서 살아남았던 addBlockedBy 교체는 새 목록에 없는 이전 의존성을 추가해 검출했다. 실제 공개 조회 테스트 파일의 무변이 결과는 35/35 통과였다. 170개 시작줄 중 미배정 0개, 추가 치환 중 미검출 0개다.
