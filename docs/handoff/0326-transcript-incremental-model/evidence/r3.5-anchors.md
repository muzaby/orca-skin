## 실행·판정

47개 행의 테스트 좌표와 검출 ID를 기존 및 신규 JSONL과 대조했다. r3.5에서 서로 다른 신규 치환 14개가 격리 사본의 해당 단언을 실패시켰고, 원본 통합 회귀는 14개 파일 106건이 통과했다. 기존 M26-a9도 새 혼합 프레임 단독 필터로 다시 실행해 1건 실패를 확인했다. 추가로 10,006자 경계 문자, 첫 user 묶음을 유지하는 pinned prepend, 지연 native 갱신의 complete 전달을 개별 실행했다. 이전 실험 중 pending anchor를 지워도 같은 렌더에서 다시 포착되는 치환은 실패 근거에서 제외했다.

Chromium headless에서 기존 최신 턴을 연 뒤 9·8·7번 턴을 하나씩 추가했을 때 글자 거리 오차 절댓값은 세 화면 모두 0.469px 이하였다. 실제 하단 이동 컨트롤을 실행하고 6번 턴을 추가하는 a4에서는 보완 전 Claude Code가 1328px에 멈춰 새 하단 2028px와 700px 차이가 났다. 보완 뒤 세 화면의 기존 하단→새 하단은 Claude Code 1328→2028px, Claude Work 1589→2429px, OpenCode 1331→1631px였고 실제 scrollTop이 각각 새 하단에 도달했다. 재생 명령은 저장소 루트에서 `node docs/handoff/0326-transcript-incremental-model/evidence/live-browser.mjs --history-replay`다.

이 표의 범위는 §10에 열거된 a/p/d/e 의미 분기와 구현자의 재현 결과다. 같은 입력에 대해 하드웨어·브라우저별 모든 타이밍을 측정한 수치나 독립 Verify 판정으로 환산하지 않는다. 통합 B/E의 페이지 요청 시점과 Windows 설치본의 AC33은 각각의 실행 항목에 남는다.

## 변경 분기 목록과 실제 전달 경로

- p/a의 파일 후보에 ChatTile과 양 Timeline, scrollTypes 및 renderer harness 계약을 포함했다. ChatTile에 추가된 JSX 속성과 TS 타입은 분기 AST가 없어 행이 나오지 않는다. ChatTile.harness.test.ts에서 실제 세 화면의 제어기와 TranscriptView를 거쳐 전달된 콜백을 렌더 후 호출해 false→true를 읽는다. 콜백을 렌더 시점의 anchored 값으로 고정한 R35-anchor-tile-pin-reader는 세 화면에서 모두 실패했다. OpenCode의 세션별 viewState·scrollPolicy, 공용 HarnessScrollController/TranscriptView 전달은 기준 커밋 뒤 제품 변경이 없는 의존성이다.
- p의 claudeBlocks에는 마지막 user reserveTarget 최초 설정·갱신이 있다. a의 Claude/OpenCode 블록, blockKeys 및 Markdown/sourceParts/CodeBlock과 실제 part·chrome을 표시하는 행 컴포넌트도 파일 후보에 넣었다. a11의 범위 측정은 top=0이면서 높이가 있는 글자, 높이=0이면서 top이 있는 글자, 둘 다 0인 빈 범위를 구분한다. 서로 다른 세 가지 치환은 각각 위 세 입력 중 한 건만 실패시켰다.
- d에는 TranscriptViewport 포커스와 claudeBlocks/blockKeys의 그룹 수명 경계를 포함했다. d7과 맞닿은 y13에서 열린 그룹을 분리한 뒤 다시 합쳐 닫고, 오른쪽 key의 저장값이 true인 상태에서 다시 분리했다. 이전 그룹의 false를 전달하지 않은 R35-anchor-split-closed는 오른쪽 DOM이 열린 채 남아 실패했다. getDisclosure의 반환형은 boolean이므로 현 구현의 undefined 검사에서 undefined 결과는 도달할 수 없다.
- e1~e8의 전환 이벤트·시한·세대 검사는 변경된 Claude ToolCard 및 공용 저장소·뷰포트의 기존 후보에 들어 있다. 파일 후보와 변경 줄 범위는 시험할 곳을 찾는 목록이다. JSX 전달, 실제 글자 위치, 분리 후 사용자가 보는 열림 여부는 실행 단언으로 판정했다.

a/p/d/e의 미겹침·문맥 후보 1,011개의 조사 구역, 새 치환 18개 및 Chromium DOM Range 글자 위치 대조는 [정책·앵커 추가 대조](r3.5-policy.md)에 기록했다.
