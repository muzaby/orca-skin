# D4 구현자 대조 · 선택 복사와 가상화

§10 규칙 분모는 c1~c19 19개와 v1~v3 3개로 총 22개다. 각 행의 ID는 실제 소스에 적용한 단일 치환이다. 여러 규칙이 같은 구현 조건을 공유할 때는 같은 ID를 참조한다. 각 JSONL의 `file`, `old`, `new`, `oracle`, `observation`으로 해당 행을 재실행할 수 있다.
