## 실제 동작 수정

r13은 이미 원 소유 표식이 있는 IPC 이벤트를 부분 이력에서 받을 때 적용된다. 송신기가 스스로 표식을 만드는 경우는 도구 완료·응답 경계 끝이고, 입력에 이미 있는 번호와 표식은 그대로 운반한다. 기존 renderer의 일곱 수신 case 중 다섯은 번호만 넘겨 부분 이력 밖의 원래 소유자 대신 새 행을 만들었다. message.reasoning, message.completed, tool.call.started, session.compacted, subagent.task에서도 받은 messageKeySource를 공통 appendAssistantPart에 넘긴다. 같은 완료 통지가 toolRunId당 한 번만 남는 기존 규칙도 보존한다. 동일 보류 주소의 재수신, reset 또는 prepend로 들어온 페이지 자체에 있는 통지, 이미 표시된 다른 행의 통지 및 같은 페이지에 도달한 보류 주소 둘을 나눠 검사했다. prepend는 이미 표시된 통지를 기존 noticeOwner 색인에서 조회한다. 동일한 7종 입력을 현재 창에 소유자가 있음, 부분 이력의 소유자 없음·표식 있음, 부분 이력의 소유자 없음·표식 없음으로 비교했다.
