## 판정 범위

새 사양 49개 중 43개에서 고장을 검출했다. 입력 불변식·생산 배선·최종 표시값에 따라 결과가 같은 6개는 위 표에 범위를 명시했다. formatter·타입 오류와 무관하게 각 치환의 직접 oracle을 실행했다. 정상 대조는 채팅·Markdown·버블 7파일 77개와 scanner 9개 검사을 통과했다. 빈 reasoning 소유자만 남은 telemetry 입력을 추가한 뒤 해당 store 검사를 다시 실행했다. 신규·기존 고유 근거 ID 153개는 corpus에서 좌표를 확인했다.

직접 실행한 새 사양은 [r3.5-stream.jsonl](r3.5-stream.jsonl)에 있다. 기존 corpus와 중복되는 ID는 위 행에서 참조했다. 공개 helper의 standalone 인수와 불일치한 scanState 검사는 생산 renderer가 항상 state를 전달하는 경로와 구별했다. 버블의 브라우저별 폭 형상은 단위 테스트의 실제 RO entry 형상으로 공급했다. Windows에서 실제 글꼴과 배율을 바꾼 측정은 §19 후속 실기에 속한다.

이후 미중첩 구문의 후보·분기·추가 검사와 실행 ID는 [버블·Markdown·델타 구문 재검색](r3.5-stream-syntax.md)에 기록했다.
