## 수정한 결과 소스 전환

하나의 tool ID에 local 결과가 있고, 그 위에 외부 map이 준 다른 결과가 있는 상태에서 마지막 call을 없앴다가 같은 ID의 call을 외부 map 없이 다시 추가했다. 변경 전에는 이전 외부 값이 남았다. 등록했던 ID의 결과를 새 call마다 다시 선택하도록 고친 후 local 결과가 복구됐다. 원래 조건으로 되돌리면 같은 입력이 실패한다. R35-core-reintroduced-source.
