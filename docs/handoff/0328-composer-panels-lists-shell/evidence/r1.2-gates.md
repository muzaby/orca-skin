# 0328 r1.2 게이트와 변이

Linux에서 Vitest와 호스트 smoke는 Node ABI의 SQLite로 실행했다. `--host`는 Electron 39.8.10의 SQLite ABI로 실행했다. [측정 방법과 원본](r1.2-measurements.md)

| 게이트 | 관측 |
|---|---|
| 마이그레이션, 문서 인벤토리, 제품 표기, 테스트 예산, 프로세스 경계 | 각각 통과. |
| 린트·타입 | 린트 오류 0, 경고 12. node·web·test 타입 검사 통과. |
| 필터 없는 Vitest | 적용 소스의 1,113파일·10,724케이스 통과. 9파일의 22개 실패 케이스를 `c7d2adf2`와 이름으로 대조한 결과 차집합은 양방향 0건이다. 미처리 거부 1건은 두 실행의 메시지가 같았다. [실패 파일과 Linux 경로 제약](r1-gates.md) |
| 전체 scripts 단위 테스트 | 1,104케이스 통과. Vitest 뒤에 별도 실행했다. |

| 기본·`--catalogs` 진단 | 이미지 표본 9회, 댓글 128개, 진단 설치 로그 DOM 30행. 산출물의 마지막 항목 도달과 예약의 보관 출력 일치 확인. |

변경된 테스트는 `measure-stage-d.test.mjs`, `install-status.test.ts`, `usePanelSelection.test.ts`, `rowMount.test.ts`다. 순수 판정, 실제 설치 스트림 전달, 가짜 DOM 선택·가상 행 ID를 각각 실행했다. 예산 위반 0건이고, 변경한 세 Vitest 파일은 unit 경로로 실제 자식 프로세스와 SQLite를 열지 않았다.

## 직접 실행한 단일 변이

독립 worktree에서 각 변이를 하나씩 적용하고 되돌렸다. 판정 테스트는 `node --test scripts/measure-stage-d.test.mjs`, 가시 행 테스트는 해당 Vitest 파일, 손상 테스트는 `node scripts/measure-stage-d.mjs --shell`을 실행했다.

| 변이 | 관측 |
|---|---|
| R-H 창 비교 제거 | `R-H uses elapsed host and window time` 실패. |
| R-H 경계 `≥`를 `>`로 변경 | 같은 테스트의 50ms 사례 실패. |
| R-H 창 시간에 DOM 행 수 추가 | 같은 테스트의 `on` 사례 실패. |
| T2를 R-H 필수 구간에서 제외 | `missing timing makes R-H and host-related R-R unavailable` 실패. |
| T5를 R-R 동기 구간에 추가 | `R-R uses task duration`에서 프레임 대기 단독 사례 실패. |
| 비교에서 생산자 출처를 제외 | `comparison checks build provenance`에서 실제/진단 라벨 사례 실패. |
| 가상 행의 `getItemKey` 생략 | `uses stable row IDs`에서 문자열 키 대신 인덱스. |
| 사이드바 목록 범위 대신 공용 owner를 사용 | `a newly mounted row only cancels`에서 형제 선택을 삭제함. |
| 중첩 목록 경계를 무시 | 같은 테스트에서 중첩 목록 선택을 삭제함. |
| 손상 store JSON 복구 옵션 끔 | 셸 재생의 `SyntaxError`와 종료 코드 1. |
