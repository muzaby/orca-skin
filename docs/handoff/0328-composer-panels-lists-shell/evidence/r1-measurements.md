# 0328 r1 · Linux Electron 진단

Electron 39.8.10을 Xorg dummy 디스플레이에서 실행했다. `app`에서 `DISPLAY=:82 node scripts/measure-stage-d.mjs`와 같은 명령의 `--catalogs`로 재생했다. 기본 진단은 이미지·입력 반복에 예열 1회와 표본 9회를 썼다. 카탈로그는 예열과 측정 각 1회다. 목록의 commit 열은 React 렌더를 포함한 `flushSync` 경과 시간이며 paint 열은 연속 두 프레임으로 잰 상한이다.

R-H의 비교에 필요한 DOM 시간 구간을 §19에 명시해야 한다. EP12는 DOM을 행 개수로 기록한다. Q20 prefix/limit, Q28 페이지, Q30 목록/상세 질의의 발동 판정은 이 비교에 달려 있다.
