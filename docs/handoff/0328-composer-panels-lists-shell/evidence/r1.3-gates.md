**추가·수정 시험의 실행 위치.** main의 폴더 감시는 파일·Dirent·watcher 수명, DB 시험은 실제 SQLite와 FTS 값을 본다. renderer 단위 시험은 UI 훅과 컴포넌트 이벤트를, shared 시험은 날짜·헤더의 경계와 레인 계약을 본다. 레이아웃·스크롤·native DOM 선택은 진단 Electron에서 확인했다. 호스트에만 Node 파일·DB 접근을 두고 창은 실제 포트로 연결했다. 이미지 응답을 의도적으로 보류한 컴포저 시험과 실제 워커를 사용한 스트리밍 겹침은 각각 별도 입력이다.

**변이 재생.** 문서의 `r1.3-mutations.jsonl`은 app 상대 경로, 단일 교체 원문, oracle 명령과 기대 종료 상태를 담는다. 저장소 루트에서 `python3 .agents/skills/handoff-verify/scripts/mutate.py docs/handoff/0328-composer-panels-lists-shell/evidence/r1.3-mutations.jsonl --cwd app`으로 재생한다. Electron의 DISPLAY와 셸 창 관리자가 필요하다. 단위 시험에는 Node ABI를 쓴다. 실행 도중에는 다른 작업이 같은 소스를 수정하지 않는 독립 checkout을 사용한다.

**동치 한 건.** Q20-symlink에서 첫 symlink 검사를 없애도 실제 디렉터리 링크와 파일 링크의 `isDirectory()`와 `isFile()`가 모두 false였다. 다음 유형 필터에서 두 항목이 제외됐다. 실제 파일과 디렉터리는 각각 한 유형만 true였다. 같은 검색·구독 시험이 green이었다. 나머지 182개는 직접 단언 실패, 제품 UI의 잘못된 결과 또는 필수 이벤트 미도착을 관측했다. 구문 오류나 하네스 초기화 실패는 검출로 세지 않았다.
