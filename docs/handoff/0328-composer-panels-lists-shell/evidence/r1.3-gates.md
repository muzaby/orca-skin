### Windows CI 후속 수정

Windows CI에서 열린 폴더를 이동한 직후 변경 통지가 0건이어서 `composer-menu-query.integration.test.ts`가 실패했다. Windows의 디렉터리 감시는 이동된 폴더 핸들을 계속 추적할 수 있다. [실패한 실행](https://github.com/muzaby/orca-skin/actions/runs/45364543333/job/138342750768)

Windows data host는 메뉴가 열린 동안 해당 경로의 실제 위치와 파일시스템 ID를 1초 간격으로 확인한다. 동일하면 창에 통지하지 않는다. 경로가 사라지거나 ID가 바뀌면 이전 감시를 닫고 기존 복구 절차를 시작한다. 마지막 구독을 닫으면 예약한 확인도 해제한다.

회귀 시험은 OS 이벤트가 없는 이동, 같은 경로의 즉시 교체, 검사 중 구독 종료, 다음 검사 전 구독 종료를 재생한다. 수정 전에는 첫 이동 통지가 0건이었고 수정 후에는 교체된 폴더를 다시 감시했다. 실제 디스크 통합 시험은 재생성한 폴더 안에서 나중에 만든 파일까지 확인한다.
