# 0328 r1.2 Linux Electron 측정과 Windows 인계

Electron 39.8.10에서 `c7d2adf2`와 적용 소스를 같은 Xorg 디스플레이로 실행했다. `app`에서 `node scripts/measure-stage-d.mjs --host`를 실행한다. 기준 소스에는 `--baseline`을 붙인다. 호스트 결과는 `node scripts/measure-stage-d.mjs --compare r1.2-host-baseline.json r1.2-host-applied.json`에 두 JSON의 경로를 넘겨 대조한다. 측정 입력은 합성 자료다. [기준 표본](r1.2-host-baseline.json), [적용 표본](r1.2-host-applied.json), [추가 기준 표본](r1.2-host-repeat.json)

## 파일·목록·예약

실제 data utility process에 임시 디렉터리와 인메모리 SQLite를 넣고 제품 핸들러·MessagePort·창 컴포넌트를 실행했다. 사례마다 예열 1회 뒤 9회를 기록했다. C1은 V8 직렬화 값의 바이트 길이이고 C2는 두 프레임 뒤 DOM 행 수다. T1~T5와 두 프레임 사이 간격을 원본 표본에서 읽을 수 있다. 이 사례에는 visible 워커 요청이 없어 T6은 `null`이다.

## 셸

`node scripts/measure-stage-d.mjs --shell`은 제품 진입점의 자산 핸들러, 창 close, 장애·종료 리스너를 추출해 격리한 Electron과 임시 파일에서 실행한다. 종료·장애 리스너는 임시 `LogManager` 및 실제 파일 transport로 연결했다. Xfwm 표본에서 자산의 기준 main 동기 최대는 4.20ms였고 응답 전체 최대는 224.97ms였다. [기준 Shell JSON](r1.2-shell-baseline.json), [적용 Shell JSON](r1.2-shell-applied.json)

| 입력 | 관측 | 유지·변경과 잔여 |
|---|---|---|
| S-D10a 각 250회 존재 CSS·누락 CSS·SPA·루트 | 각 본문과 MIME 일치. Electron 창에서 deep link가 화면을 열었다. 응답 전체 시간과 main 동기 시간은 JSON에서 별도 집계한다. | R-R 끔. 기존 파일 검사와 fallback을 보존. |
| S-D10b 자체 상태 없음·손상·세 창 모드 | Xfwm에서 일반 close `en/x=37`, 최소·최대 close 후 같은 값. 기준의 손상 JSON은 `SyntaxError`, 적용은 레거시 `en/x=5` 복구. | 상태 복구 결함 수정. Windows 재실행은 0330 인계. |
| S-D10c 1,001개 로그·주기와 회전·장애/종료 | 마지막 401개 순서 `600…1000`. 장애와 종료 직전 표식 4건이 순서대로 저장됐다. | R-R 끔. 쓰기 거부에서 파일 생성 0·오류 1건. |
