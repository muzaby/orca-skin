## Context (왜)

세션에서 핸드오프 3턴(설계/구현/검증) 규칙을 보강했으나, 자기검토 결과 ① 진입 트리거가 *트리비얼·메타 작업까지 과발동*하고 ② **이 세션 작업 자체가 핸드오프 dir 없이 직접 커밋되어 새 규칙·`0001` 선례와 불일치**, ③ 라이브 요청 출처·파생 이슈 작성주체·요청 분류·선조치 경계에 모호함이 남았다. 의도한 결과: 보정으로 규칙을 현실화하고, 이 작업을 `0045` 로 정식화해 일관성을 회복한다.

## 인수 기준 (Acceptance Criteria)

1. **A1 트리비얼/메타 카브아웃**: 진입 트리거에 "트리비얼(오타·주석·한두 줄) 및 핸드오프 인프라 자체 메타 수정은 `Handoff: none` 직접 커밋 허용, 애매하면 핸드오프 생성(설계-우선 기본값)" 가 root·handoff 양 AGENTS.md 에 명시된다.
2. **A3 라이브 출처**: plan 템플릿 의도 섹션·self-review 가 "라이브 세션 요청"을 정당한 출처로 인정한다.
3. **A4 파생 이슈 주체**: `[검증자/사용자 기입]` → `[검증자 기입]` 로 바꾸고 "사용자 코멘트는 검증자가 사용자 결정을 대리 기록" 임을 명시(템플릿·§3·충돌 최소화 정합).
4. **B1 분류 휴리스틱**: 경계 요청 판정 규칙("변경 산출물을 만들면 구현, 답/설명만이면 자료조사; 디버깅 질문이 수정으로 가면 그 시점에 트리거")이 진입 트리거에 추가된다.
5. **B2 선조치 tie-breaker**: "의심되면 ⚠️ 보고만(보수적 기본값)" 이 §2·plan 템플릿 선조치 섹션에 명시된다.
6. **B3 체크박스 연극 가드**: plan 템플릿 파생 UX·리스크에 "관련 없으면 N/A, 예시 복붙 금지" 가드가 들어간다.
7. **번호 규칙**: "마지막 일련번호 +1" → "기존 행 중 `max(번호)+1`" 로 명확화.
8. **정식화**: `0045` plan/verify + INDEX 행 + PHASES 승격으로 세션 3커밋이 회고적으로 핸드오프에 편입된다.
